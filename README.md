# Cozy Beach

Four little friends around a campfire on a low-poly beach, made as an animated wallpaper (Three.js).

- Open it: https://theprobyte.github.io/cozy-beach/
- Phone live wallpaper (Android, via a "website as wallpaper" app): https://theprobyte.github.io/cozy-beach/?wallpaper

The live weather comes from Open-Meteo for Fresno, California.
